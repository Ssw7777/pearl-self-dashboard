# 让 AI 帮你配这套看板

这个文件是给 **AI 助手**（Claude / GPT / DeepSeek / 本项目的 DSH 等）用的。
把下面「第一段」整段复制给 AI，它就会一项一项问你，然后逐步帮你把环境配好。

---

## 一、复制给 AI 的提示词

```text
你现在要帮我在我自己的电脑上部署一套 Pearl (PRL) 挖矿监控看板。
项目叫 Pearl Self Dashboard，本文件夹就是完整代码。

请你按下面的流程做，每一步都要先问我、得到答案再动手，不要自己猜：

【第 1 轮：环境体检】
- 问我：挖矿机是什么显卡？几台机器？有没有一台常开的服务器/VPS？
- 你自己跑：nvidia-smi、python --version、ping 一下矿池，把结果告诉我

【第 2 轮：功能选择】
- 把 README 第 1 节的 F1~F13 功能清单列给我，每项一句话说明，标注「必需/建议/可选」
- 逐项问我：要不要开？（一次问 3-4 项，不要一口气问 13 个）
- 我选完，你把最终清单复述一遍确认

【第 3 轮：生成配置】
按我的选择生成这些文件：
- dashboard 服务的启动方式（Linux systemd 还是 Windows 直接跑）
- agent/config.json（worker 名、收款地址、上报地址、令牌）
- thermal.json（如果我开了温度保护，问我阈值）
- games.txt（如果我开了游戏暂停，问我玩什么游戏）
- 告诉我 secrets/ctl.key 和 data/.rig_token 在哪、怎么取

【第 4 轮：部署并验证】
- 启动看板服务，打开 http://127.0.0.1:8088/ 确认能访问
- 启动 guardian.py，看日志确认 矿工/上报端 都起来了
- 等 30 秒，刷新看板，确认我的机器出现且算力不是 0
- 每一项验证结果都如实告诉我，失败了就排查，不要假装成功

【第 5 轮：交底】
- 把最终配置、启动命令、常用排障命令整理成一份 CHEATSHEET 给我
- 告诉我哪些是必需的、哪些我关掉了、以后想开怎么开

规矩：
- 不要改我的显卡驱动、不要关杀毒软件、不要动系统安全设置
- 任何要管理员权限的操作，先解释为什么，再问我要不要做
- 文件读写只用 UTF-8，不要用 PowerShell 的 Set-Content 写中文（会乱码）
- 涉及密码/令牌/地址的内容，不要写进任何会被公开的文件
```

## 二、AI 应该问到的问题（含默认值）

如果 AI 漏问了，你可以主动补上这些信息。

### A. 基础环境

| 问题 | 影响 | 默认 |
|---|---|---|
| 几台挖矿机？ | 决定 worker 数量 | 1 台 |
| 挖矿机是 Windows 还是 Linux？ | 决定 F3/F4/F11 的实现 | Windows |
| 显卡型号？ | 只影响收益估算，不影响功能 | — |
| 有没有一台常开的服务器/VPS？ | 没有的话看板就跑在挖矿机上 | 无 |

### B. 功能开关（对应 README 第 1 节）

| 编号 | 问题 | 推荐 |
|---|---|---|
| F4 | 需要 Windows 桌面控制台吗？（不要就纯网页） | 要 |
| F5 | 要温度保护吗？阈值多少度停、多少度恢复？ | 80 / 70 |
| F6 | 要「打游戏自动暂停挖矿」吗？玩什么游戏？ | 要（列出游戏名） |
| F7 | 要在网页上远程暂停/恢复吗？（需要设密码） | 看需求 |
| F8 | 多台机器要分开记账吗？（共用一个收款地址时有用） | 要 |
| F9 | 要看矿池打款记录吗？ | 要 |
| F10 | 直连矿池握手慢吗？有 VPS 的话可以中转 | 慢就开 |
| F11 | 要开机自启吗？ | 要 |
| F12 | 要绑自己域名吗？域名是什么？ | 看需求 |
| F13 | 要给朋友一个只读链接吗？ | 看需求 |
| **F14** | **要 Bark 手机推送吗？（每 30 分钟汇报 + 高温/掉线/暂停告警）** | 看需求 |

### C. 需要用户提供的值

| 名称 | 从哪来 | 放哪 |
|---|---|---|
| 收款地址 | 钱包 | `agent/config.json` → `wallet` |
| 机器名 | 自己起，唯一 | `agent/config.json` → `worker` |
| 上报令牌 | 服务端 `data/.rig_token` | `agent/config.json` → `token` |
| 控制密码 | 服务端 `secrets/ctl.key` | 网页上输入，存 localStorage |
| VPS 地址 | 自己的 | `agent/config.json` → `tunnel_host`（可选） |

## 三、AI 部署完应该交付的东西

一份 **CHEATSHEET**，至少包含：

```markdown
# 我的 PRL 看板速查

- 看板地址：http://____:8088/
- 机器名：rig-a
- 启动：cd ____ && python guardian.py
- 停止：python pearlctl.py stop
- 状态：python pearlctl.py status
- 日志：guardian.log / official.log.err
- 温度阈值：80 停 / 70 恢复（thermal.json）
- 远程控制密码：在服务器 secrets/ctl.key
- 开机自启：已配置 / 未配置
- 已开启功能：F1 F2 F3 F4 F5 F6 F8 F9 F11
- 未开启功能：F7 F10 F12 F13
```

## 四、验收清单（AI 必须逐项确认）

- [ ] `curl http://服务器:8088/api/workers` 返回 JSON
- [ ] 浏览器打开看板能看到页面（不是 502/404）
- [ ] 矿机 `guardian.state.json` 里 `state` = `mining`
- [ ] 看板上机器卡片的算力连续两次刷新都在涨
- [ ] 温度、功耗、风扇有数值（不是 `—`）
- [ ] 如果开了 F5：把 `thermal.json` 的 `hot` 临时改成 30，等 1 分钟确认自动停矿，然后改回来
- [ ] 如果开了 F7：网页点暂停，10 秒内 `manual.pause` 出现、矿工停止；点恢复能回来
- [ ] 如果开了 F11：重启电脑，确认自动开始挖
- [ ] 如果开了 F14：往服务器写 `secrets/bark.key` 后重启服务，确认手机收到一条汇报；再临时把 `TEMP_WARN` 改成 30 验证高温告警，改回 75

## 五、AI 常见坑（提前告诉它）

1. **Windows 上所有 `subprocess` 都要加 `creationflags=0x08000000`**，否则会不停闪黑窗
2. **不要用 `Set-Content -Encoding UTF8` 改中文文件**（PowerShell 5.1 会写成 GBK）
3. **`.sh` 必须是 LF 换行**，CRLF 会让 bash 报 `set: pipefail: invalid option name`
4. **`cmd.seq` 必须落盘**，否则 agent 重启会重放旧的暂停命令，把自己停掉
5. **杀毒软件会误杀矿工**，需要把项目目录加入信任区（这是用户自己的操作，AI 不要代劳关杀软）
6. **Windows 下超频参数不可用**：`--gpu-coffset` / `--gpu-fan` 会直接报错退出
7. **同型号显卡算力可能接近**：PearlHash 吃显存带宽，别看到 5060 Ti ≈ 5060 就以为坏了
8. **Bark 的 URL 里标题/正文必须整体编码**：`quote(x, safe="")`，否则正文里的 `TH/s` 斜杠会把路径拆断（表现为 404）
9. **推送必须放在服务器端**：矿机掉线时矿机发不出消息，只有服务器盯着才知道
